# Hero slideshow banner images

Drop full-bleed banner photography here to populate the homepage hero
slideshow (`components/HeroSlideshow.jsx`, rendered from `app/HomeClient.js`):

- `slide-1.jpg`
- `slide-2.jpg`
- `slide-3.jpg`

Recommended size: **1920×900px** (or similar ~2:1 landscape), JPG/WEBP,
under ~400KB each for fast loading. Text/logo detail on the *left* side
of the image will be covered by the dark gradient overlay + heading
text, so keep the most important visual content weighted to the right
two-thirds of the frame.

If a file is missing, that slide automatically falls back to a real
product photo from the live catalogue, then to a plain brand-color
panel — the slideshow never breaks, it just looks better once real
banner photography is added here.
